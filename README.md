## Project Objectives
- Analyze banking data and identify key trends.
- Monitor important banking performance indicators (KPIs).
- Understand customer behavior.
- Analyze loans and banking transactions.
- Generate data-driven business recommendations.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Project Structure

- `images/` – Dashboard screenshots.
- `PowerBI/` – Power BI dashboard file.
- `Dataset/` – Original datasets.
